## 📍 GPS PROTOCOL (Critical)

**For EVERY key point (entrance, gate, path junction, assembly area):**

1. Open **GPS Essentials** → **New Waypoint** → **Average Position**
2. Stand at **exact feature center** (door threshold, path center, gate post)
3. **Wait 60 seconds** — watch accuracy drop
4. Save as: `BLDG-ENT-001`, `GATE-001`, `PATH-JUNC-01`, `ASM-QUAD-N`
5. **Note in notebook:** `ID, Lat, Lon, Accuracy(±m), Satellites, Time`
6. **Export at day's end:** GPX + CSV → `research_data/field_observations/`

2. Describe: Entrance type, ramp/stairs, staff comments, discrepancies vs master plan

## ❓ QUESTIONS TO ASK STAFF (If EFMO/Security Companion)

| Topic | Questions |
|---|---|
| **Building Status** | "Which 'proposed' buildings are actually built now?" |
| **Entrances** | "Is this the main entrance? Any emergency exits we can't see?" |
| **Pathways** | "Is this path open to pedestrians? Any restricted sections?" |
| **Gates** | "What are exact hours? Can all gates open in emergency?" |
| **Assembly Areas** | "Which open spaces are officially designated assembly points?" |
| **Evacuation Plans** | "Are the posted diagrams the current approved versions?" |
| **Construction** | "Any current work blocking paths or entrances?" |
| **Accessibility** | "Any ramps/elevators not obvious from outside?" |
