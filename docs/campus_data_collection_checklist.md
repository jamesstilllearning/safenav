## 📍 GPS COLLECTION PROTOCOL

**App:** GPS Essentials (Android) / GPS Tracks (iOS)

**For each point:**
1. Open app → "New Waypoint" or "Average Position"
2. Stand at exact feature center (entrance threshold, path center, gate post)
3. **Wait 60 seconds** — watch accuracy improve
4. Save with **Feature ID** as name (e.g., `BLDG-ENT-001`)
5. **Screenshot or export** — note accuracy (±m) and satellite count
6. Record in notebook: `ID, Lat, Lon, Accuracy, Satellites, Time`

**Export at end of day:** GPX + CSV → `research_data/field_observations/`

## 🎤 VOICE NOTES PROTOCOL

**App:** Default voice recorder

**For each building/area:**

3. Stop recording
